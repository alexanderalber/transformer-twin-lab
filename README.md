# transformer-twin-lab

Interactive browser demos on uncertainty in transformer digital twins.

- **Duval under measurement uncertainty**: a single DGA result on the Duval triangle
  (IEC 60599, CIGRE TB 771), with a Monte Carlo cloud of possible true values.
- **Thermal mini-twin**: the IEC 60076-7 loading guide equations, hot-spot temperature
  and loss-of-life, and what a few degrees of bias do to ageing estimates.

Self-contained, offline-capable, no build step. Everything is derived from public
standards and CIGRE technical brochures, cited on each page.

Status: work in progress.

## Use and reuse

The pages are here to be used. Open them, drag the point around, show them to
colleagues, link to them, take screenshots for your own slides.
